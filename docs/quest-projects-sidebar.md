# Quest Android：侧边栏与项目

本轮将侧边栏搜索区的底部留白增至 16 dp（叠加 Android 安全区），并在搜索右边放置设置和新聊天按钮。顶部账号头像与昵称均可打开设置；顶部去掉了重复的“聊天”“设置”行，保留“能力”并新增“项目”。

“项目”包含空状态、列表、新建表单和详情页。名称和可选通用指令会保存在应用本地；系统文件选择器可添加最多 4 个文件（单个不超过 4 MB，总计不超过 8 MB），文件复制到应用文档目录。删除项目时一并删除其本地文件。项目详情可启动关联聊天，输入框会显示项目名称和文件数。

真实模型开发模式的首条消息会携带项目文件，后续消息通过会话历史复用；项目通用指令随请求发送，服务端限制其长度为 4000 字符。发布包仍使用模拟回复，明确提示项目文件尚未由真实模型解析。Google Drive 和 Box 仅显示“暂未接入”，没有账户接入或云端上传。

验证：`node --test tests/*.test.cjs` 通过 37 项，TypeScript 和本轮文件 ESLint 通过，Gradle `assembleRelease` 成功。Android 模拟器已检查侧边栏、项目导航、创建、重启后保留、系统选择器上传 TXT、项目详情、关联聊天，以及昵称和底部设置按钮跳转。截图在 `docs/screenshots/quest-projects-*.png`。
