# Quest 中英界面、个人资料与回复操作

本轮对应用户的四张参考图，继续使用已有 Expo / React Native / Uniwind 界面。

## 已实现

- 默认语言简体中文。设置 → 语言可选中文 / English，切换立即作用于聊天、侧栏、设置、资料、模型和附件入口；选择保存在本机，重启恢复。用户输入与历史消息内容不进行自动翻译。
- 默认姓名、昵称 Chiullian；用户提供的黑猫照片原样存入 `assets/images/default-avatar.jpg`，侧栏和资料区域使用同一头像。资料修改保存后共享状态同步。
- Android 输入框外侧增加 12 dp 的底部空间，属于实际测量高度，列表底部占位包含该空间。没有重复叠加键盘偏移。
- 助手回复增加灯泡耗时栏，可展开说明；保留完整 Markdown、代码块和流式正文。
- 回复下方提供复制、系统分享、赞/踩、系统朗读和重新生成。操作区域可换行。赞踩互斥，只属于本次会话，没有假装提交后端。
- 重新生成仅作用于最后一条助手回复，保留原用户问题及附件，不丢弃已输入的下一条草稿；生成中拒绝重复操作。
- 中英文模拟回复跟随发送时的界面语言，中文按小块流式输出，保留标点和 Markdown。
- 真实模式请求携带经服务端枚举校验的语言偏好。生产端仍在认证接入前关闭，不会因本轮 UI 修改开放匿名付费接口。

## 耗时与朗读的实际含义

当前安装包仍为本地模拟，所以显示“模拟耗时”，是示例文本生成的实际经过时间。真实模式没有 reasoning 部分时显示生成用时；服务返回 reasoning 部分时显示从发送到首段正文的客户端思考等待时间（包含网络等待）。不会生成或宣称获得未提供的模型内部思维链。

朗读调用手机的系统 TTS 引擎，中文/英文按回复正文选择。长文本分块排队，停止/切换新会话/卸载相关回复会停止相应朗读。声音与语言包可用性取决于手机系统。
