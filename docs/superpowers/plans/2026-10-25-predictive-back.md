# Android 项目页预测返回

用户提供的 Grok 录屏是 Android 系统返回进度驱动的圆角缩放预览，包含取消回弹。当前 app.json 与原生 Manifest 明确关闭预测返回；现有栈切换没有可供 JS 使用的系统手势进度。

实现选择：保留 Expo Router 与现有页面，新增本地 Expo Android 模块，通过 AndroidX OnBackPressedCallback 接收开始、进度、取消和提交事件。页面与返回目标的短期内存快照由原生 UI 线程绘制；不保存到文件。拖动缩小并移动当前页、露出返回目标，取消恢复，提交后才进行一次 Router 返回。只在项目相关页面聚焦时接管，键盘先处理系统返回。旧 Android 保留正常返回，系统关闭动画时跳过动画。

项目列表返回侧边栏；新建和详情返回项目列表。快照在进入项目和进入子页前捕获，只保留两份并在原生 Activity/module 销毁时释放；切到后台会中止进行中的过渡，系统文件选择器返回后仍保留返回目标预览。原生回调按页面 owner 管理，避免旧页面清理关闭新页面回调。

验证：Node 导航生命周期测试、TypeScript、ESLint、Android 原生构建；模拟器和连接真机检查按键返回、边缘返回提交、取消回弹、嵌套项目页与键盘行为。对录屏与截图逐帧检查未松手阶段。

用户追加范围：能力和设置页沿用同样的效果，并覆盖设置中的个人资料和语言页。提取通用 usePredictiveBack，按能力页入口传递返回目标。设置子页捕获 settings，侧边栏入口捕获 drawer；共享两份缓存按最近捕获顺序淘汰。设置搜索键盘先关闭再捕获，去除设置旧的卸载时恢复侧边栏逻辑。实测发现装饰头像的嵌套空 Pressable 会吞点击，改为无交互 View。验证同时覆盖直接返回侧边栏与嵌套返回设置，不修改用户资料或语言选择。
